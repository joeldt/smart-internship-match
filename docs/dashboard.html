Pourquoi un tableau plutôt qu'un graphique : pour postuler, j'ai besoin du lien, du nom de l'entreprise et du détail des compétences de chaque offre, ce qu'un graphique ne peut pas afficher lisiblement. La petite barre sous chaque score garde l'avantage visuel : on voit d'un coup d'œil l'écart entre les offres. Score = somme des (niveau / 5) de mes compétences trouvées, divisée par (compétences détectées + 1), le « + 1 » représentant ce que l'extrait tronqué ne montre pas.

Méthode et limites
  • Sources : API Adzuna et Jooble (collecte manuelle, au plus une fois par semaine, quotas gratuits limités).
  • Les deux API ne fournissent que des extraits d'offres : beaucoup d'offres n'affichent aucune compétence et sont classées « inconnues ».
  • Compétences extraites par un modèle local (Ollama, qwen3:8b), complétées par une détection par motifs de mes propres compétences.
  • Mon profil de compétences est une auto-évaluation ; les salaires estimés par Adzuna sont ignorés.
